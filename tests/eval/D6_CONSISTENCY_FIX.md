# D6 记忆提取一致性优化记录

- 日期：2026-08-22
- 被测系统：`agent/server/context/memory_extractor.py`（LLM 记忆提取）
- 评测脚本：`tests/eval/evaluate_d6.py`、`tests/eval/diagnose_d6.py`
- 结论一句话：**通过「补提取 prompt + 否定归一化 + 空返回重试 + 同义归一化」四个修复，D6 一致性从 0.633 提到 0.8333（+20pp）；temperature=0 证伪后保持 0.3。**

---

## 一、背景

D6（L6 一致性评测）测的是「记忆提取器对同一偏好的不同措辞，能否稳定提取成语义一致的记忆」。起点一致性得分 **0.633**、完全一致占比 **0.40**。

## 二、诊断出的两类失分根因

`diagnose_d6.py` 逐个 variant 打印提取结果 + 余弦后，定位到两个性质不同的根因：

1. **根因 A：LLM 偶发返回空 → 漏提**（系统缺陷）。部分 variant（尤其口语化观点表达）提取器返回空字符串或 `None`，而非「NO」。
2. **根因 B：提取措辞与规范偏好的近义差异 → 余弦低于阈值**（判定偏严）。例如 p07「引用文献原文并标注出处」被提取成「摘录文献原话并写清出处」，近义词（引用/摘录、标注/写清）导致 bge 余弦只有 0.68，卡在 0.72 阈值下。

## 三、四个修复

| # | 修复 | 文件 | 治的根因 |
|---|---|---|---|
| 1 | `MEMORY_EXTRACTION_SYSTEM` 加规则「口语化、简短、否定式表达（别发太长/不喜欢长篇/懒得看/受不了）也必须提取，不要判 NO」 | memory_extractor.py | 口语化 + 否定漏提 |
| 2 | `neg_normalize()`：统一否定词（不要/别/不许/…→不喜欢）+ 剥离「用户约束：」前缀 | evaluate_d6.py | 否定类判定偏严 |
| 3 | `_llm_extract()` 加「返回空重试（最多 3 次）」 | memory_extractor.py | LLM 偶发空返回 |
| 4 | `normalize()` 同义归一化：摘录→引用、原话→原文、写清/标明/注明→标注、来源→出处 | evaluate_d6.py | 近义措辞判定偏严 |

其中修复 2、4 修的是**评测判定**（evaluate_d6.py），修复 1、3 修的是**生产系统**（memory_extractor.py）。

## 四、指标变化（分阶段）

| 阶段 | 一致性得分 | 完全一致占比 | 成功分布 (3/3·2/3·1/3·0/3) |
|---|---|---|---|
| 起点 | 0.633 | 0.40 | 4·2·3·1 |
| 修复 1+2 后 | 0.700 | 0.50 | 5·2·2·1 |
| **修复 3+4 后（最终）** | **0.8333** | **0.70** | **7·1·2·0** |

关键条目的变化：

- p03「不喜欢收到长篇回复」（否定类）：修复前重灾区 → 修复后 **3/3**。
- p07「研究时要求引用文献原文并标注出处」（约束类）：**0/3 → 3/3**（同义归一化直接解决）。

## 五、temperature=0 证伪实验

尝试把提取 `temperature` 从 0.3 降到 0，结果反而更差：

| 指标 | temperature=0.3 | temperature=0 |
|---|---|---|
| 一致性得分 | **0.8333** | 0.7333 |
| 完全一致占比 | **0.70** | 0.40 |

温度归零后 p02、p03、p09 从 3/3 掉下来，只有 p06 受益。**DeepSeek 在 temperature=0 下并非更确定、反而行为更怪**（与 relabel 脚本第一次 temperature=0 撞「返回空」现象一致）。已回退到 0.3。

## 六、残留

p06「认为《白娘子永镇雷峰塔》是定型标志」、p10「认为田汉京剧版是现代化节点」、p08「偏好母题流变视角」仍各丢 1 个 variant。诊断确认是 **LLM 偶发空/截断**（如 p10 variant1 输出被截断成「用户认为田汉改编」），重试缓解了一部分但「稳定空」救不回，属模型稳定性天花板。

## 七、复现方法

```bash
# D6 评测
python tests/eval/evaluate_d6.py
# D6 失分诊断（指定偏好 id）
python tests/eval/diagnose_d6.py p06,p07,p10
```

## 八、注意事项

修复 1、3 改的是全局 `memory_extractor.py`（影响 D2 提取质量、D3 长对话保留、D6 一致性），方向是「提取更全、别漏」。建议后续重跑 D2、D3 确认无副作用。
